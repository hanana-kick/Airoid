# Airoid

Android端末をAirPlayレシーバーに変えるアプリです。MacやiPhoneの画面をワイヤレスで
ミラーリングし、Android端末をサブディスプレイのように使えます。AirPlayオーディオの
再生にも対応しています。

## 主な機能

- **画面ミラーリング** — H.264/H.265ハードウェアデコード、低レイテンシパイプライン
- **オーディオ受信** — AAC（ハードウェア）、ALAC（ハードウェアがない場合はソフトウェアフォールバック）
- **トランジションアニメーション** — 接続・終了時にデバイスフレーム（リング）が拡大・縮小し、映像がフェード
- **クイック設定タイル** — ミラーリング状態を表示（ACTIVE/INACTIVE）、タップでアプリを起動
- **多言語UI** — 한국어/English/日本語/中文(简体)、アプリごとの言語設定に対応
- **ペアリングコード** — 言語ごとの文学作品的タイトルでデバイスを識別（例：`Airoid 人間失格`）

## インストール

要件：**Android 8.0以降**、ARM64端末

1. 以下のリリースページから最新の `app-release.apk` をダウンロードします。
   - GitHub: <https://github.com/hanana-kick/Airoid/releases/latest>
2. ダウンロードしたAPKを開きます。「提供元不明のアプリのインストール」警告が出たら、
   ダウンロードに使ったブラウザ/ファイルマネージャーにインストール権限を許可します。
3. インストールが完了したらアプリを起動します。

アップデートも同じ方法で新しいAPKを上書きインストールするだけです
（データは保持されます）。

## 使い方

1. アプリを起動すると、スタンバイ画面にペアリングコードが表示されます（例：`Airoid 人間失格`）。
2. MacのAirPlayメニューでこのデバイス名を選択すると、ミラーリングが始まります。
3. ミラーリング中に上へスワイプすると、「ミラーリング終了」パネルが開きます。
4. （任意）クイック設定の編集で「Airoid」タイルを追加すると、状態確認とタップによる
   アプリ起動ができます。

## ライセンス

サードパーティ製コンポーネント（UxPlay、FFmpeg、libplist、openssl、oboe）はそれぞれの
ライセンスに従います。
