개인정보 처리방침

시행일: 2025년 1월 1일

Airoid는 Android 기기를 AirPlay 수신기로 쓰는 로컬 앱입니다. 앱은 개인정보를 수집하지 않습니다.

앱이 하지 않는 일

회원가입과 로그인이 없습니다. 이메일 주소, 광고 ID, 연락처, 위치 정보도 요청하거나 저장하지 않습니다.

기기 안에서만 오가는 정보

  • AirPlay 연결 때 보이는 페어링 이름은 기기 안에서 만들며, 외부로 보내지 않습니다.
  • 화면과 소리는 같은 네트워크에 있는 기기끼리만 오갑니다. 개발자 서버나 다른 회사 서버로 보내지 않습니다.
  • AirPlay를 찾으려면 로컬 네트워크 접근 권한이 필요합니다. 인터넷 연결은 필요하지 않습니다.

권한

  • 미러링을 계속 유지하고 빠른 설정 타일을 표시하려면 포그라운드 서비스와 알림이 필요합니다.
  • 마이크, 카메라, 위치, 연락처, 저장소 권한은 요청하지 않습니다.

저장과 삭제

앱은 개인정보를 저장하지 않아 따로 보관하거나 파기할 데이터가 없습니다. 앱을 지우면 캐시와 설정 같은 로컬 데이터도 함께 사라집니다.

다른 곳과 공유

개인정보를 다른 회사나 사람에게 제공하거나 처리를 맡기지 않습니다.

아동

만 14세 미만 아동의 개인정보를 수집하지 않습니다.

보안

화면과 소리는 로컬 네트워크 안에서만 이동합니다. 앱은 서명된 APK로 배포됩니다.

변경

방침을 바꾸면 이 페이지를 고치고 릴리스 노트에 알립니다.

문의

개인정보 관련 문의는 GitHub Issues로 남겨 주세요.
